# Recommendation Usage Is Durable Attribution

Food Tracker will model **Recommendation Usage** as a durable attribution layer shared by friend recommendations and creator-promoted **Creator Guides**. Usage credits both the source **Visit Item** and the **Restaurant List** or **Creator Guide** where the acting user discovered it, while **Want to Try** remains personal intent storage that preserves the original **Recommendation Source** rather than becoming the credited source.

The first durable usage actions are saved, unsaved, tried, and rated-after-try; views remain product analytics until creator monetization needs prove otherwise. **Recommendation Usage Proof** may show named activity between accepted friends, but **Creator Guide** proof defaults to aggregate or anonymized reporting. **Creator Guide Unlocks** are separate monetization events, even when creator-facing reporting combines unlocks with food-behavior usage.
